# DownloadPulse - Mobile Client

The DownloadPulse Mobile Client is a React Native app built with Expo. It receives real-time notifications when file downloads complete on your Windows PC and allows viewing download history.

## 📁 Directory Structure

```text
mobile/
├── app/            # Screens and main navigation views
├── components/     # Reusable UI components
├── services/       # Push notification & API service layer
├── constants/      # App constants, theme colors, config
├── assets/         # Images, icons, and fonts
└── README.md       # Documentation
```

## ⚙️ Execution

Run the Expo development environment using standard Expo CLI tools.
